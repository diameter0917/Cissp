search-unified audit log 指令搜尋審核 日誌。搜尋時，您可以按活動類型、使用者、文件或網站、日期範圍、工作負載進行篩選，並且 可以透過 API 匯出結果或 存取日誌以自動化。 透過該命令， 您可以監控作業進度、深入查看詳細結果， 並按操作、使用者、IP 位址、 記錄類型或專案詳細資訊進行篩選 。  需要考慮的一個實際限制是標準出口規模。匯出功能有限，因此該層級最適合進行針對性查詢，而不是大規模分析。  從概念上講，審計日誌可以幫助你講述事件經過，而你發現的內容取決於你詢問的內容。因此，選擇與你預期看到的 活動相符的篩選條件非常重要。 另一方面，審計高級版可以更深入了解使用者活動，幫助您調查敏感存取 、偵測可疑行為 並應對事件。 一個經典的例子 是使用郵件發送存取活動來調查電子郵件存取權限。 這可以顯示哪些訊息被訪問過 、被誰訪問過以及從 哪裡訪問過。  在活動中，綁定存取日誌單一電子郵件視圖，同時同步存取 日誌批次下載，例如當郵件匣同步到 Outlook 時。  還有一些實際的考慮因素，例如限制日誌記錄，在每個郵箱每天 1,000 次綁定事件後暫停記錄，並自動過濾 重複條目以減少噪音。  您可以在視圖入口網站中 分析這些事件，或者在需要進階篩選和匯出到 CSV 時使用 PowerShell，這有助於您查看 原始審核日誌中的存取類型和限制詳細資訊。 這正是審計真正發揮法務作用的地方，它可以幫助回答諸如離職員工是否查看過敏感資訊之類的問題，而不僅僅是是否下載過某些內容 。  將稽核日誌匯出為 CSV 檔案有助於進行更深入的 分析，並有助於 滿足合規性要求。流程首先在 Microsoft 權限 入口網站中執行搜索，然後選擇 Excel 以 CSV 檔案格式下載最多 50,000 條審計記錄。  若要進行分析，您可以使用 Excel 中的資料開啟 CSV 文件，然後從文字/CSV 並使用 Power Query 編輯器將 稽核資料列從 JSON 轉換為可讀列。  從那裡，您可以展開您關心的屬性，例如 IP 位址、存取類型、項目 詳細信息，以便您可以專注於相關的內容。  當您需要關聯跨服務的事件或識別異常情況（例如非工作時間的異常存取）時，此功能尤其有用。  審計資料保留是滿足監管和調查要求的重要組成部分。使用審計進階版，您可以獲得自訂保留策略， 控制 審計資料的保留時間 。  預設情況下，進階版為 Exchange、SharePoint、OneDrive 和 Microsoft Entra ID 提供一年的保留期。預設 策略無法更改，但 可以 根據具體需要覆蓋 自訂策略 。  透過自訂保留策略，您可以建立多達 50 個策略範圍，針對特定使用者、記錄類型或活動，並將資料保留時間從 7 天到 10 年不等。不過，要保留 10 年，需要額外購買許可證。  一個重要的操作細節是，資料 保留期限是在 記錄資料時確定的。因此，這些 變更僅適用於未來產生的新資料。 從風險角度來看，更長的保留期可以增強對緩慢發展的事件的抵禦能力，並有助於受監管的行業，因為調查或審計可能會追溯到數年前。  讓我們回顧一下本模組所涵蓋的內容。
