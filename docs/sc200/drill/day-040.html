03 — ⚡ 速記表：D2 回應安全性事件（35–40%）

事件回應關鍵事實

主題一句話記住
Incident vs Alert事件＝關聯後的警示集合；分診從事件層開始，別逐條追警示
裝置隔離Isolate device＝斷網保留 MDE 通道；selective isolation 留 Teams/Outlook
Live Response遠端 shell：取證（getfile、collect package）＋修復（remediate）；進階命令要開權限
AIR 自動調查自動化層級 full＝自動修復；semi＝待核准；結果進 Action center
郵件修復Threat Explorer 查 → soft delete/hard delete/move；ZAP 事後自動清已投遞郵件
MDI 偵測身分攻擊鏈：偵察→認證竊取（pass-the-hash/ticket）→橫向移動→網域支配（DCSync/黃金票證）
Entra ID Protection使用者風險（身分被盜）vs 登入風險（這次登入可疑）；風險型條件式存取自動修復
Defender for CloudCWP 工作負載警示；抑制規則消誤報；連 Sentinel 用連接器
分析規則類型Scheduled（KQL＋排程）／NRT（近即時、單表限制）／Fusion（ML 多階段）／Microsoft 安全性（產品警示直升事件）
誤報處理順序調整規則查詢/門檻 → 自動化規則自動關閉 → 抑制；別直接刪規則
自動化規則 vs Playbook改事件屬性用自動化規則；跟外部互動（通知/工單/封鎖）用 playbook（Logic Apps）
Playbook 權限Sentinel 要有 Microsoft Sentinel Automation Contributor 授權才能由自動化規則跑 playbook
UEBA實體行為基線→異常分數；養成期後才準；entity pages 看時間軸
04 — ⚡ 速記表：D3 執行威脅搜捕（20–25%）

威脅搜捕關鍵事實

主題一句話記住
KQL 心法先 where 縮小再 join；has 優於 contains；arg_max(Timestamp, *) 取最新
join 預設innerunique（左表去重）；找「沒發生」用 leftanti；保留左全量用 leftouter
Advanced hunting 表Device*／Email*／Identity*／Alert*；跨產品關聯是它的強項；30 天資料
自訂偵測advanced hunting 查詢 → custom detection rule（要有 Timestamp/ReportId/實體欄）＋自動回應動作
搜捕鏈假說（MITRE 技術）→ 查詢 → 書籤保存證據 → 升級成事件或轉分析規則
Hunts 功能Sentinel 把假說/查詢/書籤/結果打包成一個獵捕專案
Livestream即時盯一支查詢（測新規則/等攻擊者回來）；一鍵升級成分析規則
NotebooksJupyter＋MSTICPy：要機器學習/外部富化/可重複調查時才用
MITRE ATT&CK戰術＝目的（橫向移動）；技術＝手法（T1021 遠端服務）；規則與搜捕都對應到技術層
Sentinel Graph／MCP圖形關聯跨實體攻擊路徑；MCP Server 讓 AI 代理接 Sentinel 資料 2026
05 — 🎯 考試日攻略

當天流程與答題紀律

行政：提早 30 分鐘（線上監考：淨空桌面、關多餘程式、備妥證件）。考試中可用 Microsoft Learn（部分題型開放查閱）——但把它當救生圈，不是拐杖：每查一次燒 3–5 分鐘。
時間紀律：55–60 題／100 分鐘出頭。第一輪 60 分鐘掃完（會的秒殺、猶豫的先選＋標記）；第二輪處理標記題；最後 10 分鐘只檢查「看漏否定詞」。單題絕不超過 3 分鐘。
最後三條答題鐵律 ① 題目問「first / least / minimize」時，答案通常是最不可逆性低、成本最低、最自動化的選項。
② 兩個選項都對 → 選更符合題幹限定詞的那個（重讀題幹最後一句）。
③ 完全沒把握 → 刪掉兩個明顯錯的再猜，不留空白。
考完之後

無論結果如何，回來把心得記在儀表板筆記裡。過了：恭喜你完成 8 週衝刺，記得下載數位徽章；差一點：成績單會列出各領域百分比，對照本專案的領域頁立刻知道要補哪裡，改期重考的錢花在刀口上。🎉
